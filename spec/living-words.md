# Живые слова: серия стикеров, сменные подсказки, новости команды

ADR-268. Статус: 2026-11-24. Решения владельца от 2026-11-23. Развивает ADR-265 (голос) и
ADR-266 (подсказки «пока не освоил», §6 `spec/tidy-desk.md`).
Макеты: «Главная команды» (`#artboard-App-Home`), «Пустая комната» (`#artboard-App-EmptyRoom`),
«Тулбар и панели выделения» (`#artboard-App-ToolsBars`).

> Задания для разработки — `spec/dev-plan-character.md` (T12–T14).

## 1. Серия стикеров

Чтобы набросать десять мыслей подряд, сейчас нужно десять раз выбрать инструмент.

- **Удерживайте N** (клавиша инструмента) и кликайте: каждый клик ставит стикер, инструмент
  остаётся «Стикером». Отпустили N — после следующего клика инструмент возвращается к «Выбору».
- **Двойной клик по инструменту** в тулбаре закрепляет его: на кнопке маленький замок, клики
  ставят стикеры, пока не нажат Esc, V или другой инструмент.
- Поставленный стикер сразу в правке: можно печатать. Клик по пустому месту завершает правку
  и ставит следующий стикер; клик по объекту — выделяет его и снимает серию.
- Цвет — запомненный цвет инструмента (`spec/tidy-desk.md` §10a); у каждого следующего —
  свой наклон по id (ADR-265).
- То же для фигуры (R) и текста (T): механизм один, на любом инструменте создания.
- Подсказка (§2): после того как человек трижды за визит выбрал «Стикер» и поставил один
  стикер, — «Удерживайте N и кликайте — стикеры подряд». По правилам «пока не освоил»:
  исчезает после двух серий.
- Отмена: одна серия — это отдельные действия, ⌘Z убирает по одному стикеру.

## 2. Сменные подсказки

Подсказка, которую видишь в пятый раз тем же текстом, перестаёт читаться. Поэтому у каждой
подсказки 2–3 варианта: действие одно и то же, меняется посыл.

- **Реестр подсказок** (`apps/web/src/hints.ts`, ADR-266 §6) хранит для подсказки варианты:
  `{ id, variants: [{ key, intent: "action" | "benefit" | "together" }], when? }`.
  - `action` — что сделать: «Кликните дважды в любом месте — появится стикер»;
  - `benefit` — зачем: «Начните с одной мысли — порядок наведёте потом»;
  - `together` — с людьми: «Позовите коллег — они увидят ваш курсор и стикеры сразу».
- **Выбор варианта:** номер визита (счётчик подсказки в `localStorage`) по кругу — в
  пределах визита текст не меняется, на следующем — другой. `when` убирает вариант, который
  сейчас не к месту (например, `together`, если в команде уже есть люди в комнате).
- Прежние правила действуют: одна подсказка на экран, исчезает после освоения
  (`doneAfter`, `maxSessions`), никогда в деньгах, удалении, безопасности и праве.
- Все варианты пишутся по голосу ADR-265 §2 и проходят глоссарий; RU и EN — не перевод
  друг друга, а те же правила.
- **Пустая комната** (заголовок и подзаголовок) — первая подсказка с вариантами:

| Вариант | Заголовок | Подзаголовок |
| --- | --- | --- |
| action | Здесь пока тихо | Кликните дважды в любом месте — появится стикер. Или начните с одного из способов ниже. |
| benefit | Чистый лист — лучший старт | Бросьте первую мысль на стол. Порядок наведём потом — с шаблоном или агентом. |
| together | Комната ждёт людей | Позовите коллег — они увидят ваш курсор сразу. А пока — первый стикер двойным кликом. |

## 3. Новости команды на главной

Строка «Илья уже в комнате «Ретро · спринт 14», а агент разобрал вчерашние стикеры —
посмотрите, пока не остыло» работает как новость. Её собирает сервер из того, что уже знает.

### 3.1 Источники (версия 1)

| Тип | Откуда | Пример (2 формулировки на тип) | Действие |
| --- | --- | --- | --- |
| `live` | процесс синхронизации: комнаты с участниками сейчас (присутствие) | «Илья уже в «Ретро · спринт 14»» / «В «Ретро · спринт 14» сейчас Илья и ещё 2» | Присоединиться |
| `mention` | `comments` с вашим `@handle` или ответ в вашем треде, не прочитано (`comment_reads`) | «Миша ответил вам в «Онбординг клиентов»» / «Вас позвали в обсуждение в «…»» | Ответить |
| `agent` | `agent_tasks.status = 'awaiting_approval'`, поручено вами или в вашей комнате | «Агент разобрал стикеры в «…» — ждёт вашего решения» / «Агент закончил план в «…» — посмотрите, пока не остыло» | Посмотреть |
| `joined` | приглашение принято за 48 ч (`invitations.accepted_at`) | «Миша присоединился к команде» / «В команде новенький — Миша» | Позвать в комнату |

Отложено до решения владельца (нужны новые данные и ADR): «что изменилось с вашего последнего
визита» — требует таблицы визитов в комнаты.

### 3.2 Отбор: 2–3 главных

- Только комнаты, к которым у человека есть доступ (то же решение о доступе, что у комнаты;
  AGENTS.md правило 3). Никаких цитат содержимого — только названия комнат и имена людей;
  о работе агента — по названию навыка, не по тексту.
- Оценка: `вес типа × свежесть × причастность`.
  - вес: `mention` 5, `agent` 4, `live` 3, `joined` 2;
  - свежесть: половина веса за 12 ч; старше 48 ч — не показывается (`live` — только сейчас);
  - причастность ×2, если комната ваша или вы в ней писали/были за неделю.
- Разнообразие: не больше одной новости на комнату и не больше двух одного типа.
- Показ: **первая** новость — строкой под приветствием; **2–3** — карточками «Сейчас в
  команде». Нет новостей — строка под приветствием становится подсказкой с вариантами (§2),
  блок «Сейчас в команде» не показывается.
- Формулировка выбирается по `hash(id новости + дата)`: стабильна в течение дня, меняется на
  следующий. Имена склоняются только там, где шаблон написан без падежей.
- «Понятно» (крестик) скрывает новость в этом браузере (`localStorage`, id новости).

### 3.3 Сервер

- `GET /home/news?org=<id>` в сервисе синхронизации (снаружи `/api/home/news`): список до 3
  новостей `{ id, type, roomId?, roomTitle?, people: [{ name, color }], at, actionKey }`.
  Тексты собирает клиент по ключам i18n — сервер не пишет фразы.
- Присутствие `live` — из памяти процесса синхронизации (у каждой открытой комнаты есть
  участники); в двух установках — каждая про свои комнаты.
- Ответ кешируется на 30 с на пользователя; запросы ограничены последними 72 ч и комнатами
  организации.
- Метрика `news.clicked { type }` — первое за день на организацию (как `feature.used`).

## 4. Этапы

1. Серия стикеров (§1) и подсказка о ней.
2. Варианты подсказок (§2) и пустая комната с тремя вариантами.
3. Новости (§3): сервер, главная, метрика.

## 5. Приёмка

- [ ] С зажатой N три клика ставят три стикера; отпустили N — после следующего клика
      инструмент «Выбор». Двойной клик по инструменту — замок, серия до Esc.
- [ ] Каждый стикер серии сразу в правке; клик по пустому месту завершает правку и ставит
      следующий; ⌘Z убирает по одному.
- [ ] Пустая комната показывает вариант 1, на следующем визите — 2, затем 3, затем снова 1;
      в пределах визита текст не меняется.
- [ ] `GET /api/home/news` не возвращает комнаты без доступа (db-тест с двумя людьми и
      закрытой комнатой); не больше 3 новостей; не больше одной на комнату.
- [ ] Новость `mention` исчезает, когда тред прочитан; `agent` — когда предложение решено.
- [ ] Без новостей блока «Сейчас в команде» нет, под приветствием — подсказка.
- [ ] В тексте новостей нет содержимого комнат (тест: заголовок комнаты и имена — да, текст
      стикеров и комментариев — нет).
