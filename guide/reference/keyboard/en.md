## How to read this

The table below lists the keys that work while the text editor is open. On Windows and Linux use `Ctrl` for `⌘`, `Alt` for `⌥` and `Shift` for `⇧`.

## Text

| Action | Keys |
|---|---|
| Ordinary line | `⌘⌥0` |
| Heading 1 / 2 | `⌘⌥1` / `⌘⌥2` |
| Bulleted list | `⌘⇧8` |
| Numbered list | `⌘⇧7` |
| Checklist | `⌘⇧9` |
| Bold / italic / underline | `⌘B` / `⌘I` / `⌘U` |
| Strikethrough | `⌘⇧X` |
| Inline code | `⌘E` |
| Link | `⌘K` |
| Clear formatting | `⌘\` |
| Paste without formatting | `⌘⇧V` |
| Open a link on the line with the caret | `⌘Enter` |
| Indent a list item | `Tab` / `⇧Tab` |
| Next list item | `Enter` |

Pressing a list shortcut again removes the format. A shortcut acts on the line with the caret or on the whole selection. `⌘K` opens the link window, `⌘E` turns on inline code, and `⌘\` removes marks and the line format.

## On the board

| Action | Keys |
|---|---|
| Open a link | `⌘`/`Ctrl`+click |

A plain click on a link selects the object. A checklist box toggles with a plain click when you have edit permission in the room and the object is not locked.

## Place several objects

Hold **N** and click where you want each sticky note. You can type in each one immediately. Release **N** and click once more to place the last note. Use **T** for text or **R** for shapes in the same way. Double-click a tool to keep it active until you press **Esc**.
