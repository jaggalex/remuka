## Как читать

Таблица ниже — клавиши, которые работают, пока открыт редактор текста. В Windows и Linux вместо `⌘` — `Ctrl`, вместо `⌥` — `Alt`, вместо `⇧` — `Shift`.

## Текст

| Действие | Клавиши |
|---|---|
| Обычная строка | `⌘⌥0` |
| Заголовок 1 / 2 | `⌘⌥1` / `⌘⌥2` |
| Маркированный список | `⌘⇧8` |
| Нумерованный список | `⌘⇧7` |
| Чек-лист | `⌘⇧9` |
| Жирный / курсив / подчёркнутый | `⌘B` / `⌘I` / `⌘U` |
| Зачёркнутый | `⌘⇧X` |
| Код в строке | `⌘E` |
| Ссылка | `⌘K` |
| Очистить форматирование | `⌘\` |
| Вставить без форматирования | `⌘⇧V` |
| Открыть ссылку на строке с курсором | `⌘Enter` |
| Отступ пункта списка | `Tab` / `⇧Tab` |
| Следующий пункт списка | `Enter` |

Повторное нажатие сочетания списка снимает формат. Сочетание действует на строку с курсором или на всё выделение. `⌘K` открывает окно ссылки, `⌘E` включает код в строке, а `⌘\` снимает пометки и формат строки.

## На холсте

| Действие | Клавиши |
|---|---|
| Открыть ссылку | `⌘`/`Ctrl`+клик |

Обычный клик по ссылке выделяет объект. Галочка в чек-листе переключается обычным кликом по квадрату, если у вас есть право редактировать комнату и объект не заблокирован.
