# Эталоны макетов (PNG)

Снимки каждого артборда из `docs/design/mockups/` во всех состояниях, на ширине 1440 и 390 px.
По ним принимаются задания (ADR-281): «макет | продукт | разница».

- `<Артборд>/<состояние>-<ширина>.png` — снимок; список состояний и задания артборда — в
  `index.json`, там же — с какой версии холста выгружены исходники.
- Генерируются **офлайн** из исходников: `pnpm mockups:shots [Артборд …]`
  (`scripts/mockups/shoot.mjs`: свой мини-рендерер `dc-lite.js`, шрифт Golos из
  `packages/ui/src/fonts`, «уменьшенное движение» — анимации в конечном состоянии).
  Состояния описаны в `scripts/mockups/states.json`.
- Тёмная тема есть только у артбордов волны 8 (`App-Dark-*`, состояния `dark`/`light`);
  остальные экраны в тёмной теме сверяются с ними по правилам `spec/dark-theme.md`.
- Руками не правим. После выгрузки нового холста Claude перегенерирует снимки.
