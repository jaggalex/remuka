# Макеты Ремуки в репозитории

Здесь лежат **копии артбордов** дизайн-холста «Ремука — лендинг и продукт», чтобы агентам-
разработчикам не нужен был доступ к claude.ai. Холст — источник истины для людей; эта папка —
источник истины для агентов. Руками файлы не правим: изменения идут через холст, затем Claude
выгружает их сюда заново (см. «Обновление»).

## Что где

| Путь | Что это |
| --- | --- |
| `docs/design/mockups/index.json` | Карта: артборд → файл → волна → задания (T…) → ADR → папка эталонов → ссылка на холст |
| `docs/design/mockups/<Артборд>.dc.html` | Исходник артборда: разметка, **все стили инлайн**, тексты, данные и логика состояний (`renderVals()`) |
| `docs/design/reference/<Артборд>/<состояние>-<тема>-<ширина>.png` | Снимки всех состояний (1440 и 390 px) для приёмки (ADR-281); `pnpm mockups:shots` |

## Как читать исходник артборда

Файл `.dc.html` — не страница для браузера (ему нужна среда холста), а **точная спецификация**:

- **Размеры, радиусы, рамки, тени, цвета** — в атрибутах `style="…"` и в строках стилей внутри
  `renderVals()`. Например, рейка в `App-ToolsBars.dc.html`: `border-radius: 16px; padding: 8px`,
  кнопки `width: 44px; height: 44px; border-radius: 10px`.
- **Тексты** — дословно в разметке и в массивах `renderVals()`; они и есть тексты продукта
  (с поправкой на тексты из `i18n`, если макет прямо на них ссылается).
- **Состояния** — `this.state` в конструкторе и переключатели «макет: …» вверху артборда;
  `<sc-if value="{{ … }}">` — что показывается в каком состоянии.
- **`{{ имя }}`** — подстановка значения из `renderVals()`; ищите `имя:` в скрипте.
- Блоки с заметками на «стикерах» (`rotate(-…deg)`, жёлтые/розовые) — пояснения для команды,
  в продукт их не переносим.

Если в исходнике и на эталонной PNG что-то расходится — права PNG (так выглядит прототип);
сообщите владельцу.

## Как связать с заданием

1. Найдите задание в `index.json` (`"tasks": ["T15", …]`) — там все его артборды и ADR.
2. Прочитайте исходник(и) и эталоны из `reference/`.
3. Сдача — по ADR-281: страница «макет | продукт | разница» по каждому состоянию.

## Обновление

Когда владелец меняет холст, Claude выгружает изменённые артборды сюда, обновляет
`index.json` (`exportedFromVersion`) и, при необходимости, эталоны. Агенты папку не правят;
`scripts/brand-check` / `ui:check` её не проверяют (это не код продукта).
