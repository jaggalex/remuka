# Как изменить подсказку в приложении

Откройте приложение нужного региона, войдите под учётной записью оператора установки и перейдите в `/operator?tab=words`. Во вкладке «Слова» можно менять подсказки и формулировки новостей. Выбор комнаты, прав и момента показа задаёт приложение.

1. Выберите место показа и язык. Настройки русского и английского текстов сохраняются отдельно.
2. Измените нужный вариант. Под полем указан предел длины. Для новостей можно использовать подстановки, перечисленные над редактором. Предпросмотр показывает результат на примере.
3. Сохраните черновик. Проверьте формулировку и включённые варианты. Оставьте хотя бы один вариант, доступный при любых условиях.
4. Введите причину изменения и нажмите «Опубликовать». Если после подтверждения кодом из приложения прошло более 15 минут, консоль запросит свежий код.
5. Откройте продукт в новой вкладке или перезагрузите страницу. В уже открытой комнате текст сохраняется до следующей загрузки.

Если текст нужно вернуть, выберите то же место и язык, укажите причину и восстановите предыдущую версию. В аудите сохраняются версия, время, оператор и причина.

## Как читать статистику

У каждого варианта показаны число показов, число действий и их отношение за последние 28 календарных дней по UTC. Один посетитель может выполнить действие при следующем визите. Счётчики агрегируются по месту и варианту для всей установки. Значения по обоим языкам объединены. При отключённых метриках консоль сообщает, что статистика недоступна.

## Как перенести тексты между установками

Для каждой команды выберите базу соответствующей установки через переменную окружения `DATABASE_URL`. Введите её обычным для вашей установки способом работы с секретами. Экспорт создаёт новый JSON-файл с опубликованными вариантами и встроенными текстами по умолчанию.

```sh
pnpm hints:export wording-release.json
```

На целевой установке импортируйте файл, указав email действующего оператора этой установки.

```sh
pnpm hints:import wording-release.json operator@example.org
```

Перенесённые тексты появятся как черновики. При конфликте с существующим черновиком импорт прервётся целиком. Оператор проверяет каждую пару «место и язык» в целевой консоли и публикует её с указанием причины. Если каталог ещё пуст или сеть недоступна, приложение использует встроенные подсказки.
